# windows-auto-dark-mode

Автоматическое переключение системной темы Windows (светлая/тёмная) по расписанию
через встроенный Планировщик заданий — без сторонних программ.

Работает на Windows 10 и Windows 11. Не требует установки PowerToys или
Auto Dark Mode и **не требует прав администратора** — используются только штатные
средства ОС.

## Как это работает

- `theme.ps1` — меняет значения темы в реестре текущего пользователя и сообщает
  системе об изменении, чтобы панель задач и «Пуск» перекрасились сразу. В режиме
  `auto` сам выбирает тему по текущему времени.
- `install.ps1` — регистрирует в Планировщике заданий одну задачу **Theme Switcher**.
  Она запускает `theme.ps1` вечером, утром и при входе в систему. Поэтому после
  выключения или сна компьютер всегда получает тему, подходящую к текущему времени.
- `uninstall.ps1` — удаляет задачу.

Скрипт запускается полностью скрыто, без мелькания окна PowerShell.

## Установка

### Вариант 1 — просто кликом

1. Скачайте или клонируйте репозиторий в папку, где он будет лежать постоянно.
2. Дважды кликните **`install.bat`**.
3. В окне появится «Готово! ...» — задача создана, а тема для текущего времени
   применится сразу. По умолчанию: тёмная тема с 20:00, светлая — с 08:00.

### Вариант 2 — через PowerShell (например, чтобы задать своё время)

1. Скачайте или клонируйте репозиторий:
   ```powershell
   git clone https://github.com/karpalig/windows-auto-dark-mode.git
   cd windows-auto-dark-mode
   ```
2. Откройте обычный PowerShell (не от имени администратора) в папке проекта.
3. Запустите установку:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
   Своё время:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1 -DarkTime "22:00" -LightTime "07:30"
   ```
   То же самое можно сделать и через bat-файл: `install.bat -DarkTime "22:00" -LightTime "07:30"`.

Чтобы поменять время позже, просто запустите установку ещё раз с новыми значениями.

> **Не перемещайте и не удаляйте папку после установки.** Задача запускает
> `theme.ps1` из той папки, откуда выполнялась установка. Если папку нужно
> перенести — перенесите и запустите `install.bat` заново.

## Проверка

```powershell
Get-ScheduledTask -TaskName "Theme Switcher"
```

Переключить тему вручную, не дожидаясь времени:
```powershell
powershell -ExecutionPolicy Bypass -File .\theme.ps1 -Mode dark
powershell -ExecutionPolicy Bypass -File .\theme.ps1 -Mode light
```

Запустить саму задачу (поставит тему по текущему времени):
```powershell
Start-ScheduledTask -TaskName "Theme Switcher"
```

Посмотреть задачу в Планировщике: **Win+R** → `taskschd.msc`.

## Обновление со старой версии

Старые версии создавали две задачи с правами администратора
(«Theme Switcher - Dark» и «Theme Switcher - Light»). Новая установка удаляет их
сама и один раз попросит для этого права администратора (UAC). Если запрос не
появился, а старые задачи остались — удалите их вручную в `taskschd.msc`,
иначе они будут выдавать ошибку о ненайденном `run_theme.vbs`.

## Удаление

Дважды кликните **`uninstall.bat`** либо выполните:
```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

## Примечания

- Темы применяются только к текущему пользователю Windows (`HKCU`). Каждый
  пользователь компьютера устанавливает скрипт для себя.
- Если нужна привязка к реальному восходу/закату с учётом геолокации,
  для этого лучше подходит [PowerToys Light Switch](https://learn.microsoft.com/windows/powertoys/)
  или [Auto Dark Mode](https://github.com/AutoDarkMode/Windows-Auto-Night-Mode) —
  этот проект сознательно ограничен фиксированным расписанием и минимумом
  зависимостей.
